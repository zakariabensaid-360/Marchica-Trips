# Marchica Trips - Discover Nador 🌊🇲🇦

**Marchica Trips** is a modern, responsive web application designed to showcase curated travel experiences, outdoor adventures, and local guided tours in **Nador, Morocco**, and the stunning **Marchica Lagoon**. 

The platform connects travelers with authentic Moroccan hospitality, offering activities ranging from lagoon water sports to mountain hiking and culinary journeys.

🔗 **Live Website:** [https://marchica-trips-one.vercel.app/](https://marchica-trips-one.vercel.app/)

---

## ✨ Features

- **Activity Showcases:** Highlights specialized local experiences:
  - 🛶 **Kayaking:** 2-hour guided paddles along quiet turquoise lagoon waters.
  - ⛵ **Boat Trips:** Half-day coastal sailing tours exploring hidden corners.
  - 🥾 **Gourougou Hiking:** Guided forest trail treks with sweeping Mediterranean views.
  - 🫖 **Culinary Experiences:** 3-hour traditional Moroccan food and mint tea tasting sessions.
- **Dynamic Trip Planner:** An interactive entry point ("Plan your trip") allowing guests to customize itineraries based on season, group size, and weather.
- **Immersive Visuals & Testimonials:** Integrated design showcases illustrative guest stories and high-quality local photography.
- **Fully Responsive:** Optimised layout for mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

This project is built using modern frontend technologies and optimized for rapid deployment:

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have Node.js and npm installed:
```bash
node -v
npm -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd marchica-trips-one
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

### Running the Project Locally

To launch the local development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the live local version.
